# Glossary

- **Add-on** — a small single-purpose
  program inside Kodi: a scraper, a skin,
  a service. Kodi's own features mostly
  are add-ons.
- **Chorus** — Kodi's bundled web
  interface, served by Kodi itself
  (add-on id `webinterface.default`).
- **Content (type)** — what a source is
  declared to hold: movies, TV shows,
  music videos or none. Set per source;
  decides how filenames are interpreted.
- **Estuary** — Kodi's default skin
  since version 17.
- **JSON-RPC** — the method-calling
  protocol Kodi exposes over HTTP; what
  remotes, Chorus and scripts drive.
- **Library** — Kodi's database of your
  media: titles, descriptions, artwork,
  watched state. An index over your
  files, rebuildable from them.
- **Local information only** — the
  bundled scraper (`metadata.local`)
  that reads NFO files beside the media
  instead of asking the internet.
- **NFO file** — a small XML text file
  stored beside a media file, carrying
  its description in a form scrapers
  read.
- **Profile** — one person's (or room's)
  complete set of settings, sources and
  databases inside one Kodi installation.
  The first is Master user.
- **PVR** — personal video recorder:
  live TV and scheduled recording,
  supplied to Kodi by a separate backend
  program through a PVR client add-on.
- **Scraper** — the add-on that turns a
  filename into a description, from an
  online database or from NFO files.
- **Skin** — Kodi's appearance and
  layout, itself an add-on.
- **Source** — a folder (local or on the
  network) Kodi has been told it may
  look in. Not the same as library
  content.
- **Stream details** — the facts Kodi
  probes from a media file itself:
  codec, resolution, duration, channels.
- **Ten-foot interface** — an interface
  designed to be read and driven from a
  couch, ten feet from a television.
- **Userdata** — the folder tree holding
  everything personal to an installation
  (or to one profile): settings, sources,
  databases, add-on data. On Linux,
  `~/.kodi`.
- **Watched state** — Kodi's record that
  an item was played: the tick, the
  resume point, the play count. Lives in
  the database unless exported to NFO.
